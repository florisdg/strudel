# Strudel

Repo with [Strudel](https://strudel.cc/workshop/getting-started) music.

## How to play

Open any `*.strudel` file in `strudel/tracks/` and copy and paste its contents into <https://strudel.cc> and press play.

Or, use the VS Code [extension](https://marketplace.visualstudio.com/items?itemName=cmillsdev.strudelvs) and press cmd+enter.
